# Cybiture Client Delivery Kit

Use this folder when a new client books a call or signs up.

## What To Show On A Sales Call

1. Open `client-demo-workflow.md`
2. Explain the before/after workflow in plain English
3. Show `lead-tracker-template.csv` as the place their leads will be organized
4. Show the message examples in `message-templates.md`
5. Finish with `proposal-template.md`

## What To Collect From A New Client

Use `client-onboarding-checklist.md` before setup starts.

## Simple Delivery Promise

"We set up a follow-up system so every new lead is captured, tracked, and responded to faster. You get a simple dashboard, automatic alerts, and review requests without needing to learn complicated software."
