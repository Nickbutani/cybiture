# First Client Setup SOP

Use this after a client approves a plan.

## Phase 1: Confirm Scope

1. Confirm plan: Starter, Growth, or Pro
2. Confirm setup fee and monthly price
3. Confirm launch goal
4. Confirm what automations are included
5. Send onboarding checklist

## Phase 2: Collect Access

Collect:

- Website access or form embed access
- Google review link
- Booking/calendar link
- Business email
- Owner phone/email for alerts
- Existing CRM or spreadsheet, if any
- Common FAQs
- Services offered

## Phase 3: Build Lead Tracker

Use `lead-tracker-template.csv`.

Recommended statuses:

- New
- Contacted
- Follow-Up Needed
- Booked
- Completed
- Lost
- Review Requested

## Phase 4: Build Core Automation

Starter example:

1. New form submission
2. Save lead to tracker
3. Send owner email alert
4. Send customer confirmation email

Growth example:

1. New form or missed-call lead
2. Save lead to tracker
3. Send owner email/SMS alert
4. Send customer SMS/email reply
5. Send follow-up 1
6. Send follow-up 2
7. Send review request after completed job

Pro example:

1. Website chatbot qualifies lead
2. Save lead to tracker or CRM
3. Notify owner
4. Send SMS/email sequence
5. Request review
6. Review monthly and optimize

## Phase 5: Test Everything

Run at least 3 test leads:

- Test with your email
- Test with client email
- Test with mobile phone if SMS is included

Confirm:

- Lead appears in tracker
- Owner alert arrives
- Customer reply arrives
- Booking link works
- Review link works
- Follow-up timing is correct

## Phase 6: Client Walkthrough

Show the client:

- Where leads appear
- What message customers receive
- What alert the owner receives
- How to update lead status
- How review requests work

## Phase 7: Launch

Before launch:

- Client approves messages
- Client approves workflow
- Client confirms alerts are going to the right person
- Test data is deleted or labeled as test

After launch:

- Monitor first real lead
- Confirm notifications worked
- Fix any issues quickly

## Phase 8: Monthly Maintenance

Each month:

- Check automations
- Review lead tracker
- Count leads and review requests
- Send monthly report
- Suggest one improvement
